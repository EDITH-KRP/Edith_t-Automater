# HashDeep Tool Folder

Place the HashDeep executable and related files in this folder.

HashDeep is used for:
- Computing cryptographic hashes (MD5, SHA1, SHA256)
- Verifying file integrity
- Creating hash databases
- Comparing hash sets

Expected files:
- hashdeep.exe (main executable)
- md5deep.exe, sha1deep.exe, sha256deep.exe
- Configuration files
